Parte A Antes de empezar

1

Cómo funciona la seguridad (léelo antes de programar)

Toda la seguridad de la línea se apoya en una sola idea:

  1. Cada causa de emergencia es un bit que vale 1 solo mientras la causa existe (la seta está pulsada, el nivel está al 99 %…). No se memoriza.
  2. La memoria está en un único bit: Modo.Rearme_Pendiente. Se activa con cualquier causa y solo se borra al pulsar REARME cuando ya no queda ninguna causa.
  3. Modo.Parada_Seguridad = hay causa o falta el rearme. Todas las FC de la línea lo miran: si vale 1, no mueven nada.

Así, aunque sueltes la seta, la línea no arranca sola: siempre hace falta REARME y luego MARCHA.

Añadir variables nuevas a DB_Linea

FC2 necesita 3 variables nuevas en el Struct Emergencia y un Struct nuevo, Flancos. Tienes dos caminos:

Camino A · A mano

  1. Abre DB_Linea.
  2. Despliega Emergencia. Debajo de Fallo_Equipo añade Hay_Causa, Memo_Sirena y Memo_Baliza, todas Bool.
  3. Justo debajo del Struct Emergencia (al mismo nivel) crea el Struct Flancos con sus 8 Bool.

EmergenciaMemo_BalizaBoolBaliza parpadeando: desde que aparece una emergencia hasta que se completa el rearme.

   VAR 
      Modo : Struct
         Auto : Bool := FALSE;   // Selector en AUTO.
         Ciclo_Marcha : Bool := FALSE;   // Ciclo automatico en marcha: se generan botellas.
         Fin_Ciclo : Bool := FALSE;   // Se pulso PARO. No se generan mas botellas; las de la linea terminan.
         Linea_Vacia : Bool := TRUE;   // No queda ninguna botella en la linea (FIFO vacio).
         Rearme_Pendiente : Bool := TRUE;   // Se activa con cualquier causa y solo se borra con REARME cuando ya no queda ninguna. Arranca a 1 al encender la CPU.
         Parada_Seguridad : Bool := TRUE;   // Resumen: hay alguna emergencia activa o memorizada. Para todo y cierra la valvula de seguridad.
      END_STRUCT;
      Emergencia : Struct
         Seta : Bool := FALSE;   // Causa activa ahora: seta pulsada.
         Nivel_99 : Bool := FALSE;   // Causa activa ahora: tanque al 99 %.
         Tiempo_40s : Bool := FALSE;   // Causa activa ahora: alguna botella pasa de 40 s. La escribe FC9.
         Manual : Bool := FALSE;   // Causa activa ahora: selector en MANUAL.
         Fallo_Equipo : Bool := FALSE;   // Causa activa ahora: alguna fase tiene un fallo rojo. La escribe FC10.
         Hay_Causa : Bool := FALSE;   // Resumen: alguna de las 5 causas esta activa ahora.
         Memo_Sirena : Bool := FALSE;   // Sirena sonando: se activa al aparecer una emergencia y se silencia con REARME.
         Memo_Baliza : Bool := FALSE;   // Baliza parpadeando: desde que aparece una emergencia hasta que se completa el rearme.
      END_STRUCT;
      Flancos : Struct
         Marcha_FM : Bool := FALSE;   // Memoria de flanco de PB_Marcha. No se usa para nada mas.
         Rearme_FM : Bool := FALSE;   // Memoria de flanco de PB_Rearme.
         Seta_FM : Bool := FALSE;   // Memoria de flanco de Emergencia.Seta.
         Nivel99_FM : Bool := FALSE;   // Memoria de flanco de Emergencia.Nivel_99.
         T40_FM : Bool := FALSE;   // Memoria de flanco de Emergencia.Tiempo_40s.
         Fallo_FM : Bool := FALSE;   // Memoria de flanco de Emergencia.Fallo_Equipo.
         Marcha_Pulso : Bool := FALSE;   // Vale 1 durante un solo ciclo al pulsar MARCHA.
         Rearme_Pulso : Bool := FALSE;   // Vale 1 durante un solo ciclo al pulsar REARME.
      END_STRUCT;
      Tanque : Struct
         Nivel_Pct : Real := 0.0;   // Nivel del tanque en % (desde IW64).
         Nivel_25 : Bool := FALSE;   // Sensor 25 % usado por el programa. Viene de I3.3 o, en simulacion, de Nivel_Pct >= 25.
         Nivel_90 : Bool := FALSE;   // Sensor 90 % usado por el programa (I3.4 o Nivel_Pct >= 90).
         Nivel_99 : Bool := FALSE;   // Sensor 99 % usado por el programa (I3.5 o Nivel_Pct >= 99).
         Bomba_Marcha : Bool := FALSE;   // Bomba pedida: SET por debajo del 25 %, RESET al 90 % o con emergencia.
         Aviso_Nivel_Bajo : Bool := FALSE;   // Nivel por debajo del 25 %: el llenado de botellas espera (naranja).
      END_STRUCT;
      Llenado : Struct
         Caudal_Lmin : Real := 0.0;   // Caudal instantaneo en l/min (desde IW66).
         Volumen_L : Real := 0.0;   // Litros que han entrado en la botella actual.
         Consigna_L : Real := 0.0;   // Litros a alcanzar: 90 % de 0,5 L = 0,45 L - 90 % de 2 L = 1,8 L.
         En_Curso : Bool := FALSE;   // Valvula de llenado abierta, sumando litros.
         Malas_Seguidas : Int := 0;   // Botellas malas consecutivas. 3 seguidas = rojo A303.
      END_STRUCT;
      Generador : Struct
         Peticion : Bool := FALSE;   // Se cumplen las condiciones para pedir una botella nueva.
      END_STRUCT;
      Cajas : Struct
         Cnt_Malas : Int := 0;   // Botellas en la caja de malas (0...20).
         Cnt_05L : Int := 0;   // Botellas en la caja de 0,5 L (0...6).
         Cnt_2L : Int := 0;   // Botellas en la caja de 2 L (0...6).
         Cambiando_Malas : Bool := FALSE;   // Cambio de caja de malas en curso (naranja).
         Cambiando_05L : Bool := FALSE;   // Cambio de caja de 0,5 L en curso (naranja).
         Cambiando_2L : Bool := FALSE;   // Cambio de caja de 2 L en curso (naranja).
      END_STRUCT;
      Reloj : Struct
         Base_100ms : DInt := 0;   // Se suma 1 cada 100 ms en el OB30. Sirve para medir el tiempo de cada botella (40 s = 400).
      END_STRUCT;
   END_VAR
   VAR RETAIN
      Produccion : Struct
         Total_Buenas_05L : DInt := 0;   // Contador historico de botellas buenas de 0,5 L.
         Total_Buenas_2L : DInt := 0;   // Contador historico de botellas buenas de 2 L.
         Total_Malas : DInt := 0;   // Contador historico de botellas malas.
         Total_Cajas_05L : DInt := 0;   // Cajas de 0,5 L completadas.
         Total_Cajas_2L : DInt := 0;   // Cajas de 2 L completadas.
         Total_Cajas_Malas : DInt := 0;   // Cajas de malas completadas.
      END_STRUCT;
      Param : Struct
         Simulacion_FIO : Bool := TRUE;   // TRUE = niveles desde el nivel analogico (Factory I/O). FALSE = sensores reales I3.3-I3.5.
         Max_Botellas : Int := 3;   // Botellas a la vez en la linea (1 a 4).
         T_Espera_Emision : Time := T#8s;   // Tiempo minimo entre dos botellas nuevas.
         Limite_Botella_100ms : DInt := 400;   // Tiempo maximo de una botella en la linea: 400 x 100 ms = 40 s.
         Pct_Llenado : Real := 90.0;   // Porcentaje de llenado objetivo.
         Vol_Botella_05 : Real := 0.5;   // Capacidad botella pequena (L).
         Vol_Botella_2 : Real := 2.0;   // Capacidad botella grande (L).
         Caudal_Max_Lmin : Real := 10.0;   // Caudal que corresponde a 27648 en IW66. A calibrar con Factory I/O.
         Apertura_Llenado : Int := 13824;   // Apertura de la valvula de llenado: 13824 = 50 %.
         T_Max_Llenado_05 : Time := T#6s;   // Si en este tiempo no se llega a 0,45 L, la botella es MALA.
         T_Max_Llenado_2 : Time := T#10s;   // Si en este tiempo no se llega a 1,8 L, la botella es MALA.
         T_Taponado : Time := T#2s;   // Tiempo con el cabezal de TAP-01 abajo (apriete del tapon).
         T_Max_Cilindro : Time := T#3s;   // Tiempo maximo de movimiento de TAP-01 y del empujador. Si se pasa: rojo.
         T_Cambio_Caja : Time := T#3s;   // Duracion del cambio de caja (retirar + poner nueva).
         Cap_Caja_Buenas : Int := 6;   // Botellas por caja de buenas.
         Cap_Caja_Malas : Int := 20;   // Botellas por caja de malas.
         T_Max_Relleno_Tanque : Time := T#120s;   // Bomba en marcha mas de este tiempo sin llegar al 90 %: aviso naranja.
      END_STRUCT;
   END_VAR

Crear FC2

  1. Agregar nuevo bloque › Función (FC). Nombre FC_Modos_Seguridad, lenguaje KOP, número manual 2.
  2. Esta FC no necesita variables en la interfaz: todo lo que usa está en DB_Linea y en la tabla de variables.
  3. Vas a hacer 20 segmentos. Están agrupados en 6 pasos; pon a cada segmento el título que indica la guía.

Segmentos 6 y 7 · Pulsos de MARCHA y REARME

Ojo Cada |P| necesita su propio bit de memoria y ese bit no se usa en ningún otro sitio. Si repites un bit de memoria en dos flancos, los dos fallan.
Truco Por eso sacamos el pulso a una variable (Marcha_Pulso): la podemos usar en todos los segmentos que queramos sin repetir el flanco.

Llamar a FC2 desde el OB1

  1. Abre Main [OB1]. Añade un segmento debajo del de FC1.
  2. Arrastra FC_Modos_Seguridad al segmento 2. Título: FC2 · Modos y seguridad.
┃      ┌──────────────────────┐
┃      │ "FC_Modos_Seguridad" │
┃──────┤EN                 ENO├───
┃      └──────────────────────┘

El orden importa: FC1 prepara los sensores y FC2 decide si la línea puede funcionar. Todas las FC que vengan después usarán lo que FC2 ha decidido en este mismo ciclo.

Parte C Probar en PLCSIM

11

Preparar las tablas de prueba

En TIA: tabla de observación

  1. En el árbol: PLC_Linea › Tablas de observación y forzado permanente › Agregar tabla de observación. Nombre: Obs_FC2.
  2. Escribe estas variables, una por fila: "DB_Linea".Modo.Auto, "DB_Linea".Modo.Ciclo_Marcha, "DB_Linea".Modo.Fin_Ciclo, "DB_Linea".Modo.Rearme_Pendiente, "DB_Linea".Modo.Parada_Seguridad, "DB_Linea".Emergencia.Hay_Causa, "DB_Linea".Emergencia.Memo_Sirena, "DB_Linea".Emergencia.Memo_Baliza, "VS_Valvula_Seguridad", "Sirena" y "Baliza_Naranja".
  3. Pulsa Observar todo (las gafas) cuando el PLC esté en RUN.

En PLCSIM: tabla SIM

  1. Compila y carga como en la Parte 1.
  2. En la tabla SIM añade "SETA_Emergencia", "PB_Paro", "SEL_Auto", "PB_Marcha", "PB_Rearme", "AI_Nivel_Tanque".
Ojo PLCSIM arranca con todas las entradas a 0. Para el PLC eso es seta pulsada, PARO pulsado y MANUAL, porque la seta y el PARO son NC. Así que lo primero que verás es la sirena sonando: es lo correcto.
Truco Para simular que pulsas un botón en la tabla SIM, pon su valor a 1 y enseguida otra vez a 0. En PARO es al revés, porque es NC: de 1 a 0 y otra vez a 1.

Las 13 pruebas de FC2

Hazlas en orden. Cada fila parte de cómo quedó la anterior.

#Qué hacesQué debes ver
0Nada: acabas de cargarSirena = 1 · Baliza parpadea · Rearme_Pendiente = 1 · VS = 0
1SETA = 1 · PARO = 1 · SEL_Auto = 1 · AI_Nivel_Tanque = 13824Hay_Causa = 0 · Rearme_Pendiente = 1 · la sirena sigue sonando · VS = 0
2Pulsa REARMERearme_Pendiente = 0 · Parada = 0 · Sirena = 0 · Baliza = 0 · VS = 1
3Pulsa MARCHACiclo_Marcha = 1
4Pulsa PARO (1 → 0 → 1)Ciclo_Marcha = 0 enseguida, porque no hay botellas en la línea
5Pulsa MARCHA y luego pon SETA = 0Sirena = 1 · Baliza parpadea · Ciclo_Marcha = 0 · VS = 0
6Con la seta aún a 0, pulsa REARMESirena = 0 · la baliza sigue · Rearme_Pendiente = 1
7SETA = 1 y pulsa REARMETodo limpio · VS = 1 · Baliza = 0
8SEL_Auto = 0Parada = 1 · VS = 0 · sin sirena ni baliza
9SEL_Auto = 1 y pulsa MARCHA sin rearmarNo arranca: Rearme_Pendiente = 1. Pulsa REARME y ya puedes
10AI_Nivel_Tanque = 27400Sirena = 1 · Baliza parpadea · VS = 0
11AI_Nivel_Tanque = 13824 y pulsa REARMETodo limpio · VS = 1
12PB_Prueba_Lamparas = 1Baliza_Naranja = 1 fija mientras lo mantengas
Truco Si una prueba falla, abre FC2 y pulsa Activar/desactivar observación (las gafas del editor). Verás en verde por dónde pasa la corriente en cada segmento y encontrarás el fallo enseguida.
